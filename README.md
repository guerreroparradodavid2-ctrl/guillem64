# Guillem the Frutem Adventure - port N64 (etapa 1)
Port no oficial y simplificado. Juego original: https://zacdev.itch.io/guillem-the-frutem-adventure
Controles: stick = mover, C izq/der = girar, C arriba/abajo = mirar, A = saltar, B o Z = correr, START = reiniciar.
Compilar: `make` (necesita libdragon). El ROM sale como guillem.z64.
