# Guillem the Frutem Adventure - port N64 (no oficial)
Juego original: https://zacdev.itch.io/guillem-the-frutem-adventure
Funciona SIN Expansion Pak (4 MB). Tercera persona: tu eres la pera.
Controles: stick = mover, C izq/der = girar camara, C arriba/abajo = inclinar, A = saltar, B o Z = correr, START = reiniciar.
Compilar: lo hace GitHub Actions (.github/workflows/n64.yml). Los datos se regeneran con tools/make_assets.py (necesita tools/data2.json).
